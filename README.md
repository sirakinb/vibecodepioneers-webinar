# Vibe Code Pioneers Webinar: Claude Code for Beginners

![Vibe Code Pioneers](/builder.png)

This project is the landing page for the **"Claude Code for Beginners: A Live Build Session"** webinar, hosted by **Akinyemi Bajulaiye** for the **Vibe Code Pioneers** community.

## Overview

The webinar is a live demonstration designed to demystify **Claude Code**—Anthropic's advanced coding agent. Instead of a lecture, this session focuses on a real-time build, showing users how to go from idea to working application using AI-native workflows.

**Webinar Date:** Sunday, January 26th, 2026 @ 4:00 PM EST  
**Host:** Akinyemi Bajulaiye  
**Topic:** Building apps from scratch with Claude Code vs. Lovable/Bolt/Replit.

## Tech Stack

- **Framework:** React (Vite)
- **Styling:** CSS Modules / Vanilla CSS (with responsive design)
- **Animation:** Framer Motion
- **Icons:** Lucide React
- **Routing:** React Router DOM

## Key Features

- **"Warm Dark" Aesthetic:** A custom theme inspired by Anthropic's branding (`#0f0e0e` bg, Crimson Text serif headers).
- **Registration Modal:** Integrated with a **Make.com** webhook to capture sign-ups (`firstName`, `lastName`, `email`).
- **Responsive Design:** Optimized for mobile and desktop viewing.
- **Glassmorphism UI:** Premium feel with subtle gradients and glass-effect cards.

## getting Started

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/sirakinb/vibecodepioneers-webinar.git
    cd vibecodepioneers-webinar
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Run the development server:**
    ```bash
    npm run dev
    ```

4.  **Build for production:**
    ```bash
    npm run build
    ```

## Project Structure

- `src/components/`: Reusable UI components (Hero, Features, Details, Modal).
- `src/index.css`: Global variables (colors, typography) and reset.
- `src/App.css`: Component-specific styling.
